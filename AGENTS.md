# Agent and contributor rules

Applies to people and coding agents alike.

## Filing issues

- Search existing issues first.
- One problem per issue.
- At most about 150 words plus the repro. No AI-generated summaries, no filler.
- No speculative fixes: report what you observed, not what you guess the cause is.
- Use the issue forms; include version, OS, accelerator, command and full output.

## Pull requests

- Pull requests from outside contributors are by invitation: open an issue first and wait for a maintainer to ask for a PR. PRs are limited to collaborators.
- Every PR links an issue, stays on one concern, and states how it was tested.

Build, test and lint commands are in [CONTRIBUTING.md](./CONTRIBUTING.md).
