The frontend lives under `web/` in the amicu monorepo - a Turborepo + pnpm
workspace containing the Next.js app, the shared design system, and config.

## Prerequisites

- Node.js >= 18
- pnpm (via `corepack enable pnpm`)

## Install and run

```bash
cd web
pnpm install
pnpm dev        # start apps/web (marketing + app + /docs)
```

Then open:

- `/` - marketing landing
- `/app` - authenticated product shell (placeholder)
- `/docs` - this documentation

## Build and checks

```bash
pnpm build      # turbo build (includes the /docs route)
pnpm lint
pnpm typecheck
```

## AI-friendly docs

Fumadocs generates machine-readable exports at build:

- `/llms.txt` - index of documentation pages
- `/llms-full.txt` - full documentation as a single text stream
- `/docs/<page>.md` - per-page Markdown (content negotiation)
