---
title: credential
description: A named bundle of secret references.
---

A `credential` groups secret references. Every field takes `secret("NAME")`; a literal value is rejected at parse time (`AMICU-POLICY-004`). See [Secrets](/docs/security/secrets).

## Example

```hcl
resource "credential" "registry" {
  token = secret("HF_TOKEN")
  env {
    EXTRA_VAR = secret("EXTRA_SECRET")
  }
}
```

## Fields

| Field | Type | Required | Description |
|---|---|---|---|
| `api_key` | `secret(...)` | no | An API key reference |
| `token` | `secret(...)` | no | A token reference |
| `password` | `secret(...)` | no | A password reference |
| `env` | block | no | Map of environment variable name to `secret(...)` |

<Callout title="Not wired to deployments yet">
  A `credential` is parsed and stored, but no field refers to it in this version. Set a deployment's endpoint key with `api_key = secret("NAME")` on the deployment itself.
</Callout>
