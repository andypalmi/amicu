`amicu apply` runs deployments on this machine and on Modal only. The providers below are not wired into `apply`. A deployment that targets one fails at apply with a clear error and nothing is started.

You can still use them in a `hardware_profile`: `validate` and `plan` use their region and pricing catalogs for residency and cost checks.

## Preview

The provisioning adapter is built and tested against mocks. It has not been tested live.

| Provider | Id | Residency |
|---|---|---|
| Hetzner | `hetzner` | Germany, Finland, plus US and APAC |
| OVHcloud | `ovhcloud` | France, Germany, Poland, plus non-EU regions |
| Scaleway | `scaleway` | France, Netherlands, Poland |
| RunPod | `runpod` | EU and EEA data centers, plus US, Canada, and APAC |
| Self-hosted over SSH | | The location you declare for each host |

## Planned

## What to do today

To run on one of these providers, provision the machine yourself, install the runtime there, and run amicu on that machine with a local provider (`on_prem`). The endpoint then binds to loopback on that host.

See the [providers page](/providers) for the current status table.
