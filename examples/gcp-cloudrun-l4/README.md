# Google Cloud (Cloud Run, one L4)

vLLM serving Qwen3-0.6B (fp16) on Cloud Run in `europe-west4`, one L4 per instance, at most one instance, scaled to zero when idle. Replace `your-gcp-project-id` (also in `service_account`, an account you create first: see the docs page), run `gcloud auth application-default login`, export `CHAT_API_KEY` (a random key, for example `openssl rand -hex 32`) and run `amicu apply`. The endpoint is the service's `https://*.run.app` URL: it is public, and the API key is its only guard. Any request, even an anonymous one, can start a billed L4 instance (at most one here) until it is idle again; set `access = "iam"` in the `gcp {}` block to let only callers with a Google identity token in. The key lives in Secret Manager and `amicu destroy` deletes it with the service. See https://amicu.dev/docs/providers/gcp.
